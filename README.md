# مشغّلي · Mushaghili

**مشغّل فيديو لأجهزة آيفون بتصميم Liquid Glass** · *A Liquid Glass video player for iPhone*

مشغّل فيديو لأجهزة آيفون، مبنيّ باستخدام Expo (React Native)، بواجهة داكنة وتصميم Liquid Glass.

## المزايا

- **المشغّل:** تشغيل الفيديو من رابط مباشر (mp4 / m3u8) أو من ملفات الجهاز، وأزرار تحكّم تختفي تلقائيًا، وتقديم وترجيع بمدة قابلة للتخصيص، وشاشة كاملة أفقية، ووضع صورة داخل صورة.
- **الترجمة:** يبحث زر «جلب الترجمة تلقائيًا» عن ترجمة مضمّنة داخل الفيديو أولًا، ثم في OpenSubtitles باسم الفيديو. ويمكن أيضًا فتح ملفات srt و vtt من الجهاز أو من رابط، مع دعم الترميز العربي (UTF-8 و Windows-1256) وضبط التوقيت والحجم.
- **التلفاز:** العرض على التلفاز عبر AirPlay من أزرار النظام.
- **المشاهدة الجماعية:** غرفة برمز خاص تُزامِن التشغيل والإيقاف والتقديم بين جهازين (عبر خدمة ntfy.sh). تعمل مع الروابط فقط دون ملفات الجهاز، وتبقى الترجمة خاصة بكل مستخدم.
- **الإعدادات (جديد في 1.3):** من زر الترس أعلى الشاشة: واجهة بخمس عشرة لغة (العربية افتراضيًا)، وسرعة تشغيل افتراضية وزر للسرعة داخل المشغّل (0.5–2×)، ومدة التقديم 5 / 10 / 15 / 30 ثانية، والتشغيل التلقائي، والاستئناف من آخر موضع، وحفظ مستوى الصوت، وتشغيل الصوت في الخلفية، وتفعيل صورة داخل صورة تلقائيًا، والنقر المزدوج للتقديم، والاهتزاز اللمسي، وإبقاء الشاشة مضاءة، وملاءمة الفيديو أو ملء الشاشة، ولغة الترجمة التلقائية مع لغة احتياطية، ومظهر الترجمة (الحجم واللون والخلفية والموضع)، ومسح السجل والذاكرة المؤقتة. ترجمات اللغات غير العربية والإنجليزية لم يراجعها متحدثون أصليون بعد.
- **Liquid Glass:** يستخدم التأثير الزجاجي الأصلي في iOS 26 وما بعده، ويعود إلى تأثير التمويه (Blur) إن لم يكن متاحًا.

## التثبيت عبر SideStore

1. نزّل ملف `.ipa` من صفحة [أحدث إصدار](https://github.com/za7ef/mushaghili/releases/latest).
2. افتح الملف في SideStore ليُوقَّع بحساب Apple الخاص بك ويُثبَّت.

## بناء ملف IPA بنفسك

1. من GitHub انتقل إلى **Actions** ← **Build unsigned IPA** ← **Run workflow**.
2. بعد انتهاء البناء (نحو 15–25 دقيقة)، نزّل `mushaghili-ipa` من صفحة التشغيل وفُكّ ضغطه.
3. افتح الملف `mushaghili.ipa` في SideStore.

> ملاحظة: تمنح الحسابات المجانية في GitHub دقائق محدودة لأجهزة macOS في المستودعات الخاصة، أما المستودعات العامة فدقائقها مجانية.

## التشغيل محليًا (على جهاز مثبّت عليه Node)

```bash
npm install
npx expo start
```

## ملاحظات

- بثّ شاشة الجهاز كاملةً (ReplayKit) غير متاح حاليًا؛ إذ يتطلب إضافة بثّ (Broadcast Extension) وخادم بثّ.
- يعتمد البحث التلقائي عن الترجمة على واجهة OpenSubtitles القديمة دون حساب، وإن توقفت فستُضاف خانة لمفتاح API.
