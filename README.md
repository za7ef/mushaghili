# مشغّلي 🎬

مشغّل فيديو للآيفون مسوّى بـ Expo (React Native)، بتصميم داكن و Liquid Glass.

## وش فيه

- **المشغل:** تشغيل من رابط مباشر (mp4 / m3u8) أو من ملفات الجوال، أزرار تختفي لحالها، تقديم وترجيع 10 ثواني، شاشة كاملة بالعرض، وصورة داخل صورة.
- **الترجمة:** ملفات srt و vtt من الجوال أو من رابط، تدعم العربي (UTF-8 و Windows-1256)، مع ضبط التوقيت والحجم.
- **التلفزيون:** AirPlay من أزرار النظام.
- **نتفرج سوا:** غرفة بكود، والتشغيل والإيقاف والتقديم يتزامن بين جوالين (عن طريق ntfy.sh). الروابط بس، مو ملفات الجوال. والترجمة تبقى عند كل واحد.
- **Liquid Glass:** يستخدم الزجاج الأصلي في iOS 26 وفوق، ولو مو متوفر يرجع لتأثير Blur.

## تجربه بسرعة (بدون ماك)

1. نزّل **Expo Go** من App Store.
2. افتح https://snack.expo.dev/loFpwFNBN21Lmy_hfKUBK من سفاري واختر "Open in Expo Go"، أو امسح الكود.

## تبنيه IPA وتثبته بـ SideStore

1. في GitHub روح **Actions** ← **Build unsigned IPA** ← **Run workflow**.
2. لما يخلص (تقريبًا 15–25 دقيقة)، نزّل `mushaghili-ipa` من صفحة التشغيل وفك الضغط.
3. افتح الملف `mushaghili.ipa` في SideStore، وهو يوقّعه بحساب أبل حقك.

> ملاحظة: الحسابات المجانية في GitHub تعطيك دقائق محدودة لأجهزة macOS في المستودعات الخاصة. لو المستودع عام فالدقائق مجانية.

## تشغيل محلي (لو عندك جهاز فيه Node)

```bash
npm install
npx expo start
```

- البحث عن الترجمة من داخل التطبيق مو موجود لأن مواقع الترجمة تطلب حساب ومفتاح API.
